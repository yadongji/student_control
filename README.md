# 学生信息与周末留校登记系统

完全离线运行，适合约 2000 名学生。图形界面使用 Python 自带的 Tkinter，学生与每周登记数据保存在本目录的 `student_data.json`。

## 启动

直接双击 `启动系统.bat`。该启动文件已经使用本机 Python：

`C:\Users\Administrator\AppData\Local\Programs\Python\Python314\python.exe`

也可以在 PowerShell 中运行：

```powershell
& "C:\Users\Administrator\AppData\Local\Programs\Python\Python314\python.exe" "D:\student_control\student_gui.py"
```

## 学生公共字段

- 学号（唯一，用于查找学生）
- 姓名
- 住宿情况：走读留铺、走读无铺、住宿
- 性别
- 宿舍号
- 床位号
- 班级

## 每周登记字段

- 周五晚留校
- 周六上午在校
- 周六下午留校
- 周六晚上留宿
- 周日留校

每个字段只有 0 和 1 两种状态。界面使用大按钮，灰色表示不留（0），绿色表示留校（1），适合使用触摸屏或鼠标现场录入。点击后自动保存。

## 导入与导出

导入的 XLSX 第一行必须是表头，至少包含“学号”列。系统能识别“学生姓名/姓名”“寝室号/宿舍号”“行政班/班级”等常见列名。

如果导入表没有学号列，文件名必须包含班级编码，例如 `107班宿舍安排.xlsx`。系统会识别 `107` 为班级，再按“姓名 + 班级”在已有学生中查找，并补充宿舍号、床位号等字段；找不到或匹配到多人的记录会显示在顶部通知栏，不会误写入。

导入时按学号查重：新学号会新增；学号相同但姓名不同会拒绝导入，并在顶部通知栏显示冲突双方；学号和姓名相同、其他内容也相同会直接跳过；学号和姓名相同但班级、宿舍等内容有变化时会更新公共信息。任何导入都不会清除原来的每周记录。

如果班级为空，系统会按学号自动补全班级：默认取学号第 5 至第 7 位的三位编码。例如学号 `2026107xxxx` 会自动得到班级 `107`（其中首位为级部、后两位为班号）。手动新增、修改和导入时都会执行这个判断；如果表格已填写班级，则以表格内容为准。

导出文件包含本周全部登记明细、人数统计，以及五个时段各自的留校名单。界面上的“当前周”使用该周周一的日期作为标识。

原命令行版本 `student_control.py` 保留备用；正常使用请运行 `student_gui.py`。
